# Game A

3D-шутер на Godot 4.3.

- 2 команды (Красные / Синие), командный огонь выключен
- 4 оружия: пистолет (1), автомат (2), дробовик (3), снайперка (4), перезарядка R
- 2 карты: «Арена» и «Коридоры»
- Игра по LAN: один игрок жмёт «Создать сервер», остальные «Подключиться» по его IP (порт 7777)
- Счётчик FPS в левом верхнем углу

## Управление (ПК)
WASD — движение, мышь — обзор, ЛКМ — огонь, Пробел — прыжок, 1–4 — оружие, R — перезарядка, Esc — отпустить мышь.

## Управление (телефон)
Левая часть экрана — стик движения, правая средняя часть — обзор, кнопка ОГОНЬ, R — перезарядка, цифры сверху — оружие.

## Сборка APK
Сборка идёт в GitHub Actions (`.github/workflows/build-apk.yml`) при пуше в `main`.
Готовый APK лежит в артефактах запуска: `game-a-apk`.

## Известные ограничения
- Урон считает клиент стрелка и передаёт его владельцу цели (без сервер-проверки) — для друзей норм, для турниров нет.
- Подключиться к уже идущему матчу нельзя.
- Ассеты примитивные (кубы и капсулы), звуки генерируются кодом.
